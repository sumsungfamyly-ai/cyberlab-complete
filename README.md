# CyberLab Defensive Toolkit — готовый к деплою стартовый проект

CyberLab — русскоязычная учебная панель по кибербезопасности с тёмным интерфейсом, каталогом 70+ безопасных инструментов и Telegram-ботом. Проект предназначен для защиты, обучения и анализа собственных ресурсов. Он **не собирает пароли, коды подтверждения, cookie или Telegram-сессии** и не содержит функций кражи учётных данных.

## Что реально работает в проекте

- Адаптивная веб-панель: поиск, категории, карточки инструментов и окно описания.
- Инструменты в браузере: анализ структуры URL, оценка пароля локально, генератор парольной фразы, SHA-256, Base64, URL-кодирование, просмотр JWT payload, JSON formatter, regex-песочница, UUID, временные метки, сравнение текста, CSV → JSON, матрица риска, шаблоны IOC/инцидента и учебный квиз.
- API `/api/health` для проверки деплоя.
- API `/api/analyze-url` для эвристического разбора URL без сетевого обращения к целевому сайту.
- Telegram webhook `/api/telegram` с командами `/start`, `/help`, `/tools`, `/status`, `/url`.
- Скрипт установки webhook, `.env.example`, тесты и инструкции.
- Каталог инструментов содержит 70+ записей; часть — практические чек-листы/справочные карточки, а не отдельные сканеры. Это отмечено в интерфейсе.

## Требования

- GitHub-аккаунт.
- Vercel-аккаунт.
- Telegram-бот, созданный через официальный BotFather.
- Node.js 20+ для локального запуска тестов.

## Деплой на Vercel

1. Распакуйте архив.
2. Создайте новый репозиторий на GitHub и загрузите **содержимое папки** проекта.
3. В Vercel нажмите **Add New → Project**, импортируйте репозиторий и нажмите Deploy. Фреймворк можно оставить `Other`; Build Command и Install Command не требуются.
4. В Vercel → Settings → Environment Variables добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather.
   - `TELEGRAM_WEBHOOK_SECRET` — случайная строка из букв A-Z, a-z, цифр, `_` и `-`, длиной 32+ символа.
   - `APP_NAME` — необязательно.
5. Сделайте redeploy после добавления переменных.
6. Установите webhook с локального компьютера, где установлен Node.js 20+:
   - Windows PowerShell: `$env:TELEGRAM_BOT_TOKEN="ваш_токен"`
   - `$env:TELEGRAM_WEBHOOK_SECRET="ваш_секрет"`
   - `$env:APP_BASE_URL="https://ваш-проект.vercel.app"`
   - `node scripts/set-telegram-webhook.mjs`
7. Откройте в браузере `https://ваш-проект.vercel.app/api/health` — ожидается JSON с `"ok": true`.
8. Напишите своему боту `/start`, затем `/tools` и `/url https://example.com`.

## Локальная проверка

Нужен Node.js 20+:
```bash
npm test
npm run check
```
Для Windows можно запускать эти команды в PowerShell из папки проекта.

## Безопасность и ограничения

- Не загружайте реальные пароли, OTP, API-ключи, cookie, seed-фразы и приватные данные.
- Оценка URL эвристическая и не является вердиктом о безопасности сайта.
- Инструмент анализа URL не открывает целевой сайт и не делает сетевой запрос к нему.
- Telegram webhook использует заголовок `X-Telegram-Bot-Api-Secret-Token`; не публикуйте токен и секрет.
- Это не полноценная SIEM, антивирус, pentest-сканер или сервис проверки репутации. Справочные пункты — это чек-листы и обучающие инструкции.
- В проекте намеренно нет сбора паролей, перехвата кодов, кражи сессий, массовой рассылки фишинга или эксплуатации чужих систем.

## Честно о «полностью готово»

Проект подготовлен к деплою, но внешние аккаунты и секреты нельзя настроить за вас из архива. Перед публичным запуском обязательно выполните шаги выше и проверьте бота в своём Telegram. Я не могу обещать «идеальную» работу до запуска в вашем Vercel-проекте: у каждого аккаунта свои домены, настройки и лимиты.
