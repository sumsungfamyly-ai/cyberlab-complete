# Архитектура

## Frontend
`public/index.html` — адаптивный интерфейс без обязательной сборки. Каталог загружается из `public/tools.json`. Практические операции, для которых предусмотрен интерфейс, выполняются в браузере.

## Serverless API
- `api/health.js` — статус API.
- `api/analyze-url.js` — серверный endpoint, который разбирает URL как строку, не делает запрос к адресу назначения и возвращает эвристические признаки.
- `api/telegram.js` — Telegram webhook; требует токен и секрет заголовка.

## Telegram
`/start`, `/help`, `/tools`, `/status`, `/url <URL>`. Команда `/url` анализирует только структуру ссылки. Бот не предназначен для передачи секретов.

## Пределы
Каталог содержит и утилиты, и учебные чек-листы. Это не автоматический сканер инфраструктуры, не SIEM и не платформа управления инцидентами.
