# Приватность

- Не вставляйте в браузерную панель реальные секреты, даже если операция выполняется локально.
- Веб-приложение загружает каталог `tools.json` и проверяет endpoint `/api/health`.
- Telegram-бот получает сообщения, отправленные пользователем самому боту, как часть работы Telegram Bot API.
- URL-анализатор не открывает целевой сайт и не проверяет его репутацию.
- До публичного запуска добавьте собственные юридические документы, контакты владельца и политику хранения логов, если они требуются для вашего использования.
