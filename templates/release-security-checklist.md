# Security checklist перед релизом

- [ ] Секреты отсутствуют в репозитории и сборочных артефактах.
- [ ] Зависимости проверены и обновлены по политике.
- [ ] Аутентификация и авторизация протестированы.
- [ ] Входные данные валидируются на сервере.
- [ ] Ошибки не раскрывают секреты и внутренние трассировки.
- [ ] Логи не содержат пароли, OTP, токены и лишние персональные данные.
- [ ] HTTPS и безопасные заголовки настроены.
- [ ] Резервное копирование и восстановление проверены.
- [ ] Указаны владелец сервиса и канал сообщения об инциденте.
- [ ] Проведена проверка доступности и базовой мобильной адаптации.
